# Smart Home Jarvis

Інтелектуальна система керування розумним будинком на базі Home Assistant, Python та локальної мовної моделі Qwen 2.5 3B.

## Про проєкт

Мета проєкту — розробити прототип розумного будинку з централізованим керуванням пристроями, автоматизацією процесів та AI-асистентом Jarvis.

Jarvis приймає команди користувача звичайною мовою, визначає потрібну дію та передає команди до Home Assistant.

## Архітектура системи

- **Серверна частина:** Home Assistant OS 18.4, запущена у VirtualBox.
- **Система керування:** Python.
- **AI-модель:** Qwen 2.5 3B через Ollama (локальний запуск).
- **Взаємодія:** текстові команди через консоль.
- **Керування пристроями:** Home Assistant REST API.

## Реалізовані можливості

- Увімкнення та вимкнення розумної лампи.
- Керування витяжкою.
- Керування обігрівачем.
- Перегляд стану будинку.
- Команда вимкнення всіх пристроїв і режимів.
- Розпізнавання природних команд, наприклад «Мені темно».
- Розуміння контексту попередньої команди, наприклад «Вимкни її».
- Автоматизації та режими в Home Assistant.

## Встановлення та запуск

1. Встановити Python.
2. Встановити Ollama та завантажити модель:

```bash
ollama pull qwen2.5:3b
```

3. Встановити залежності:

```bash
pip install -r requirements.txt
```

4. Створити файл `.env` на основі `.env.example` та вказати адресу Home Assistant і власний токен доступу.

5. Запустити Home Assistant та переконатися, що він доступний за вказаною адресою.

6. Запустити Jarvis:

```bash
python jarvis.py
```

## Безпека

Файл `.env` містить приватний токен доступу до Home Assistant і не повинен завантажуватися до GitHub.
