# Архітектура Smart Home Jarvis

## 1. Загальна структура

Система складається із серверної частини, програмного модуля керування та клієнтського інтерфейсу.

## 2. Серверна частина

Як серверну основу використано Home Assistant OS 18.4, запущену у віртуальній машині Oracle VirtualBox на комп'ютері з Windows 11.

Home Assistant відповідає за зберігання станів пристроїв, виконання автоматизацій та обробку команд.

## 3. Інтелектуальний модуль Jarvis

Jarvis реалізований мовою Python. Він приймає текстові команди, визначає цільовий пристрій та потрібну дію.

Для локальної обробки мовних запитів використовується модель Qwen 2.5 3B через Ollama.

Зв'язок із Home Assistant здійснюється через REST API з використанням токена доступу.

## 4. Керовані компоненти

У прототипі реалізовано програмні моделі таких пристроїв:

- Розумна лампа.
- Обігрівач.
- Витяжка.
- Датчик руху.
- Датчик дверей.
- Датчики температури та вологості.

## 5. Принцип роботи

1. Користувач вводить текстову команду.
2. Jarvis аналізує команду та визначає потрібну дію.
3. Python надсилає запит до Home Assistant.
4. Home Assistant змінює стан відповідного компонента.
5. Jarvis повідомляє користувача про результат.

## 6. Програмне середовище

- Операційна система комп'ютера: Windows 11.
- Віртуалізація: Oracle VirtualBox.
- Серверна операційна система: Home Assistant OS 18.4.
- Мова програмування: Python 3.13.
- Локальна модель: Qwen 2.5 3B.
- Середовище запуску моделі: Ollama.

## 7. Особливості прототипу

Поточна версія демонструє принципи централізованого керування розумним будинком. Керовані пристрої представлені програмними компонентами Home Assistant, а не фізичним обладнанням.
